# Universal Life System

React + TypeScript + Vite local-first personal life app.

## Run in Codespaces
```bash
npm install
npm run dev -- --host 0.0.0.0
```
Open forwarded port 5173. Production check: `npm run build`.

## Included
Command Center, Missions, Planner, Dream Life goals, Personal Evolution, Knowledge Library, Rewards, Journal, Reports, Settings, local JSON backup/restore. Add/edit/delete/complete actions are implemented. Completing a mission awards XP and credits; rewards can be redeemed with credits.

## Limits
Data is stored in this browser's localStorage, not encrypted or synced. Export backups regularly. AI model connections, cloud sync, authentication, Android APK packaging, Health Connect, smartwatch integrations, calendar sync and external automations are not implemented. No external messages, purchases or transactions are made.
